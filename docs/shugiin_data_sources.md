# 衆議院（国政）活動データ 取得先設計（案）

## 目的
- 公約進捗・言行一致のスコア算出に必要な「活動データ」を確保する。
- 公式の公開情報に限定する。

## 主な取得先（公式）
1. 国会会議録検索システム（発言・質疑）
   - 内容: 本会議/委員会の発言、質問、答弁
   - 目的: 活動量、テーマの一貫性、発言と投票の整合
   - メモ: API は `https://kokkai.ndl.go.jp/api/search` を想定（要確認）
   - 注意: 現在この環境からは 403 でブロックされることを確認。GitHub Actions 等での検証が必要。

2. 衆議院公式サイト（議案・質問主意書）
   - 内容: 議案一覧、提出者、質問主意書の一覧
   - 目的: 「行動（提出・質問）」の裏付け
   - メモ: `/internet/itdb_jp.nsf/` 系の公開ページを利用予定（要確認）

3. 衆議院公式サイト（採決結果）
   - 内容: 本会議の採決結果（賛否）
   - 目的: 発言と投票の一致度
   - メモ: 本会議の「採決結果」ページを利用予定（要確認）

## 取得→整形の流れ
1. 候補者名 → 現職議員の名簿で照合（ローマ字・表記揺れ対策）
2. 会議録APIで発言取得
3. 議案/質問主意書の提出履歴取得
4. 採決結果から賛否行動を取得
5. `activities` と `votes` に集約して JSON 化

## JSON への追加（想定）
```json
{
  "role": "incumbent",
  "activities": [
    { "type": "speech", "date": "2025-11-12", "topic": "子育て", "source": "会議録URL" },
    { "type": "question", "date": "2025-12-01", "topic": "防災", "source": "質問主意書URL" }
  ],
  "votes": [
    { "bill_id": "xx", "date": "2025-12-15", "topic": "税制", "position": "賛成", "source": "採決URL" }
  ]
}
```

## 次のアクション
- 公式URLの正確な取得先を検証
- 取得形式（HTML/CSV/JSON）を確定
- `scripts/` に収集スクリプト追加
